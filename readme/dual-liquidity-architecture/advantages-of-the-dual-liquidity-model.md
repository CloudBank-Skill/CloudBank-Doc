# Advantages of the Dual Liquidity Model

The integration of GLP + CLP creates a hybrid liquidity structure that solves many limitations of traditional DEXs.

#### **Benefits**

* **Scalability:** Major assets rely on GLP, while long-tail assets use CLP
* **Risk Isolation:** Long-tail volatility does not affect system-level liquidity
* **Market Diversity:** Thousands of markets can be created without impacting core stability
* **Community Empowerment:** Liquidity ownership returns to users and creators
* **Efficient Depth:** GLP provides institutional-level depth for high-volume trading

This architecture ensures CloudBank can support a wide variety of assets and markets—from global blue-chip tokens to locally defined community economies.
