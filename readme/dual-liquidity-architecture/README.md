# Dual Liquidity Architecture

At the core of CloudBank lies its most important innovation: the **Dual Liquidity Architecture**, a system composed of the **Global Liquidity Pool (GLP)** and the **Community Liquidity Pool (CLP)**.\
This two-layer design enables CloudBank to support deep, stable liquidity for major assets while simultaneously empowering communities to create their own markets with independent liquidity.

The result is a flexible, scalable liquidity ecosystem capable of supporting everything from institutional-grade trading to grassroots market creation.
