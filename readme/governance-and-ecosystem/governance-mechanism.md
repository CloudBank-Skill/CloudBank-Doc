# Governance Mechanism

CloudBank follows a "Progressive Decentralization" model, shifting from team-maintained to a fully decentralized DAO driven by COD holders.

Four Core Capabilities:

1. On-chain Proposals: Submit formal improvement proposals.
2. Token-weighted Voting: Governance power is proportional to staked COD.
3. Protocol Parameter Governance: Authority over fee rates, margins, and pool parameters.
4. Ecosystem & Capital Approval: Oversight of Grants and Treasury allocations.
