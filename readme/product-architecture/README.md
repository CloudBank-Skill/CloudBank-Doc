# Product Architecture

CloudBank is a full-stack DeFi super application composed of **five core product modules**, all built on top of the Dual Liquidity Architecture.\
Each module interacts seamlessly with both the GLP and CLP, creating a unified financial ecosystem that supports trading, fundraising, prediction markets, algorithmic strategies, and digital payments.

These modules can function independently or together, empowering users, communities, and projects with a powerful set of tools to build decentralized financial applications.
