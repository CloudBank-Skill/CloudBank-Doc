# Launchpad

The Launchpad is CloudBank’s decentralized fundraising and token issuance system, fully integrated with both GLP and CLP liquidity.

#### **Key Features**

* Fair launches and community-driven fundraising
* Customizable token sale parameters
* Support for over-subscription, vesting, and whitelist models
* Fully on-chain and transparent

#### **Why It’s Unique**

* Liquidity created during fundraising directly links to post-launch markets
* Projects can bootstrap liquidity through CLP without relying on centralized exchanges
* DAO-based project selection and community governance

Launchpad allows projects to raise funds and immediately activate sustainable on-chain liquidity.
