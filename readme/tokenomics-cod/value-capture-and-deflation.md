# Value Capture & Deflation

Protocol Revenue Distribution:

R(burn) = 26% \* R\
R(stakers) = 22% \* R\
R(node) = 30% \* R\
R(treasury) = 5% \* R\
R(team) = 5% \* R\
R(insurance) = 12% \* R

Buyback & Burn: The protocol mandates a buyback and burn of at least 26% of revenue to enforce continuous deflation and scarcity.
