# Value Proposition

CloudBank's unique value is derived from three key capabilities:

1. Permissionless Market Creation: Any community can establish trading pools, prediction markets, or contract markets while defining their own models, assets, and tokenomics.
2. Dual Liquidity Structure (GLP + CLP): This industry-first architecture solves structural bottlenecks such as fragmented liquidity and the inability of communities to participate in base-layer liquidity. It enables the sustainable scaling of a financial ecosystem driven by open liquidity.
3. All-in-One Financial Infrastructure: CloudBank is not merely a protocol; it is a comprehensive infrastructure fusing a DEX, Perps, Launchpad, Prediction Markets, AI Quantitative Strategies, and Cross-Chain Payments into one composable platform.
